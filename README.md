# Phillis Brown Books

Author site for Phillis Brown: a wood bookshelf where each book turns to show its cover, opens into its own page, and links to a read-along reader with narration.

- `index.html`: the shelf, book pages and About the author
- `covers/`: book covers (full size and small shelf versions)
- `img/`: author portrait
- `read/<book>/`: the reader for each book, with its audio
- `start/`: the start screen: rendered frames, the candle-flicker loop, the opening clip and its music (a start menu asks for sound, a tap opens the book, then the shelf)

All books are for adult readers (18+).

## Publish with GitHub Pages

Settings > Pages > Build and deployment > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. The site appears at `https://jvtomax99.github.io/phillis-bookshelves-/` a minute or two later.
